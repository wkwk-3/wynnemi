WEI 2.1.0-test.8（テスト版）。Minecraft 1.21.11 / Fabric 用。

必要なもの: Wynntils、Fabric API、PF-EMI（別に入れてください。WEI は EMI を同梱しません）。
あると使える機能: Wynnventory（高額アイテムの通知）、Mod Menu（設定画面）。

## test.7 からの変更

見た目や操作は変わりません。中身の整理と、不具合を調べやすくするための変更です。

- 何も記録せずに無視していたエラーを、場所ごとに 1 回だけログに出すようにした（`[WEI] Ignored an error in ...`）
- Wynntils のデータ取得完了の通知を受けたときの処理を、ゲームのスレッドに寄せた（別スレッドから状態を書き換えないように）
- EMI の読み込み待ちの判定と「EMI が最後に読み込んだ内容」を、それぞれ 1 つの値で持つようにした（途中の状態を読まないように）
- アイテム一覧を作る処理を別のファイルに分けた（動作は同じ）
- 検索語の解析などに自動テストを追加した
- FORK.md の Mixin 一覧を実際のコードに合わせた

不具合があれば、ログ（`logs/latest.log`）を添えて報告してください。
