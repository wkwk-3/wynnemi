WEI（Wynn Enough Items）2.0.0。Minecraft 1.21.11 / Fabric 用。

必要なもの: Wynntils（4.2.18 で確認）、Fabric API。EMI はこの jar に同梱しているので、EMI や PF-EMI を別に入れないでください。
あると使える機能: Wynnventory（高額アイテムの通知）、Mod Menu（設定画面）。

## 1.0.0 からの変更

### 新機能
- 高額アイテムの通知: ルートチェスト・ローラン報酬・レイド報酬・イベント報酬で、取引所の価格（Wynnventory）が基準以上のアイテムを点滅する枠で囲み、音を鳴らす
  - 判定に使う価格（最安値・平均・80%平均・中央値・最高値）、基準額、色、音を変えられる
  - アイテムの種類とレア度ごとに基準額を追加できる（「通知しない」も可）
  - 未鑑定ボックスは中身の候補のうち一番高いもので判定
- 条件検索の画面: 種類・ティア・レベル範囲・攻撃速度・職業・ID・メジャーIDを選んで EMI の検索欄に入れる（インベントリ左上のボタン、`/wei search`）
- 未鑑定ボックスで R/U を押すと、その箱の中身の候補だけを表示
- アスペクトを1種類1件にまとめ、ティアごとの必要数（累計）をレシピ画面で表示
- 否定検索（`-rarity:mythic` など）
- Mod Menu からの設定画面

### 変更
- 一覧から外したもの: 名前に「֎」が付いた重複、廃止アイテム、クエスト専用装備、ID のないイベント景品
- ルーン・パウダー・キーなど名前の無いアイテムのキーを、言語に左右されない ID に変更（古いお気に入りは自動で引き継ぎ）

### 修正
- アイテム名がバニラの名前（「クラフト不可能なポーション」など）になり、名前検索が効かなかった
- 一覧の作成直後に作った一部の装備の説明文が名前だけになっていた
- EMI がアイテム一覧の完成前に読み込まれ、お気に入りが消えることがあった
- 読めなかったお気に入りや履歴が消えていた／Wynntils 側のお気に入りが勝手に外れることがあった

## 既知の問題
- 手持ちのルーンで R/U が効くかは未確認
- MOD 一覧のアイコンが未設定

## 3.0.0 で削除予定の互換処理
2.x のうちに設定・お気に入り・履歴が新しい形式で保存し直されるため、3.0.0 で次の読み替えをやめます。
- 1.0.1 より前のアスペクトのキー（`aspect/名前 T2`）と、名前の無いアイテムの表示名キー（`rune/Az Rune` など）
- 設定の旧初期色（橙）の移行
- 2.1.0 より前に履歴・お気に入りへ保存された、未鑑定ボックスの一時スタックの掃除
