WEI（Wynn Enough Items）2.1.0。Minecraft 1.21.11 / Fabric 用。

必要なもの: Wynntils（4.2.18 以降）、Fabric API、**PF-EMI**（Modrinth の 1.21.11 用。2.1.0 から EMI は同梱していません。別に入れてください）。
あると使える機能: Wynnventory（高額アイテムの通知）、Mod Menu（設定画面）。

## 2.0.0 からの変更

### 重要
- EMI の同梱をやめ、PF-EMI を前提にしました。2.0.0 から更新するときは PF-EMI を mods フォルダに入れてください。WEI に必要な EMI 側の変更は Mixin で差し込んでいます。PF-EMI の更新で差し込めなくなった場合は、ログに警告が出てその機能だけ止まります

### 新機能
- 条件検索の画面を EMI の検索欄の右のアイコンから開くように変更
  - 力・器用さ・知力・防御・敏捷の必要値とボーナスの範囲検索
  - ID を一覧から選べるように（範囲を空にすると「その ID を持つもの」、一覧は A→Z / Z→A で並べ替え）
- EMI の検索欄のハイライト表示（ダブルクリック）で、手持ちやチェストのアイテムを WEI の検索語（`tier:` `id.` など）でも判定して暗くする
- 設定画面の診断ログを「自動／オン／オフ」の 3 段階に（自動はプレリリース版だけ出す）
- MOD のアイコン

### 修正
- 手持ちのルーンなど、名前の前に見えない字送り文字が付いたアイテムが一覧のアイテムに対応づかなかった
- 未鑑定ボックスの R/U で、その場限りのスタックが履歴に残り続けていた
- 高額アイテムの枠が、価格の分からないアイテムに入れ替わっても残っていた
- EMI のハイライト表示の暗転が見えていなかった（WEI が描き直す）
- 手で書き換えた設定ファイルの欠けた値で通知の判定が落ちることがあった
- 正式リリース版で診断ログが出続けることがあった（旧設定の `diagnostics` を無視）

## 既知の問題
- ルーンには入手元・使い道のデータが無いため、R/U を押しても何も表示されない

## 3.0.0 で削除予定の互換処理
2.x のうちに設定・お気に入り・履歴が新しい形式で保存し直されるため、3.0.0 で次の読み替えをやめます。
- 1.0.1 より前のアスペクトのキー（`aspect/名前 T2`）と、名前の無いアイテムの表示名キー（`rune/Az Rune` など）
- 設定の旧初期色（橙）の移行
- 2.1.0 より前に履歴・お気に入りへ保存された、未鑑定ボックスの一時スタックの掃除
